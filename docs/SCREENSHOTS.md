# Image notes

The four PNGs in this directory show the existing Canvas interface rendering demonstration content. They are unchanged from the public source and match the prepared release assets byte-for-byte. No new UI, browser or service was launched to produce them.

| Image | Content |
| --- | --- |
| `canvas-mockup.png` | Two synthetic habit-tracker phone layouts rendered as HTML inside Canvas. |
| `canvas-openui.png` | OpenUI checkout chart and table with illustrative metrics, dark theme. |
| `canvas-html.png` | HTML capacity plan and decision form with illustrative costs. |
| `canvas-pane.png` | Canvas pane surface with the checkout example, light theme. |

The mockup's phone shapes and controls are HTML content rendered inside Canvas. The pane image doesn't establish acceptance inside the real OpenChamber app. Original capture process/host hasn't been independently verified. The images show generic demo project and agent labels; figures are examples and aren't performance benchmarks.

All four are 1380 pixels wide, with heights of 1000 pixels except the 955-pixel pane image. Their PNG containers have only image chunks (IHDR, IDAT and IEND), with no text or EXIF metadata.

The AI-generated comic marks in `assets` are the approved existing artwork. The 32-pixel mark is a mechanical preview of the badge. Artwork terms and third-party attribution are in [RIGHTS.md](../RIGHTS.md).
